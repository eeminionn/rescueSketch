# Support / Soporte

## English

Choose the channel that matches your request:

| Need                                          | Channel                                                                                                  |
| --------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| How-to question, idea, or design conversation | [GitHub Discussions](https://github.com/eeminionn/rescueSketch/discussions)                              |
| Reproducible product bug                      | [Bug report](https://github.com/eeminionn/rescueSketch/issues/new?template=bug-report.yml)               |
| Suspected rules mismatch                      | [Rules discrepancy](https://github.com/eeminionn/rescueSketch/issues/new?template=rules-discrepancy.yml) |
| New tile or catalogue element                 | [Catalogue proposal](https://github.com/eeminionn/rescueSketch/issues/new?template=catalog-piece.yml)    |
| Security vulnerability                        | Follow [SECURITY.md](SECURITY.md) privately                                                              |

Before asking, search existing discussions and issues, state the RescueSketch
version or commit, and provide the smallest reproducible example. Never post
credentials, access tokens, private keys, or personal information.

Community support is best effort. Competition-day rulings must be requested
from the relevant event officials; RescueSketch maintainers cannot issue an
official RoboCup ruling.

## Español

Elige el canal correspondiente:

| Necesidad                               | Canal                                                                                                         |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| Pregunta, idea o conversación de diseño | [GitHub Discussions](https://github.com/eeminionn/rescueSketch/discussions)                                   |
| Error reproducible del producto         | [Reporte de bug](https://github.com/eeminionn/rescueSketch/issues/new?template=bug-report.yml)                |
| Posible discrepancia reglamentaria      | [Discrepancia de reglas](https://github.com/eeminionn/rescueSketch/issues/new?template=rules-discrepancy.yml) |
| Nueva baldosa o elemento de catálogo    | [Propuesta de catálogo](https://github.com/eeminionn/rescueSketch/issues/new?template=catalog-piece.yml)      |
| Vulnerabilidad de seguridad             | Sigue [SECURITY.md](SECURITY.md) en privado                                                                   |

Antes de consultar, busca discusiones e issues existentes, indica la versión o
commit y entrega el ejemplo reproducible más pequeño. Nunca publiques
credenciales, tokens, claves privadas ni información personal.

El soporte comunitario es de mejor esfuerzo. Las decisiones durante una
competencia corresponden a sus oficiales; quienes mantienen RescueSketch no
pueden emitir una resolución oficial de RoboCup.
