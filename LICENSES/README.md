# Licence map / Mapa de licencias

RescueSketch uses a deliberate licence split. A file-specific SPDX identifier
or notice overrides this general map.

RescueSketch usa una separación deliberada de licencias. Un identificador SPDX
o aviso específico del archivo prevalece sobre este mapa.

| Path or material / Ruta o material                                                                                                                                                                                    | SPDX              | Licence / Licencia                     |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------- | -------------------------------------- |
| Source code, tests, configuration, and repository documentation unless marked otherwise / Código, pruebas, configuración y documentación salvo aviso distinto                                                         | `MIT`             | [MIT](../LICENSE)                      |
| Original community track documents in `communityTracks/` / Documentos originales de pistas en `communityTracks/`                                                                                                      | `CC-BY-4.0`       | [CC BY 4.0](CC-BY-4.0.txt)             |
| Original RescueSketch explanations and graphics explicitly marked as adapted from rules material / Explicaciones y gráficos originales de RescueSketch expresamente marcados como adaptados de material reglamentario | `CC-BY-NC-SA-4.0` | [CC BY-NC-SA 4.0](CC-BY-NC-SA-4.0.txt) |
